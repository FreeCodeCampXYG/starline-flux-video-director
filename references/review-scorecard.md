# 人工审片评分卡

每段先正常速度看一遍，再逐帧看接缝。每项 0–2 分。

| 项目 | 0 | 1 | 2 |
|---|---|---|---|
| 叙事效用 | 无明确用途 | 可用但弱 | 设置—事件—收束清楚 |
| 事件可读性 | 原因/结果混乱 | 基本可读 | 因果和方向明确 |
| 构图与镜头 | 漂移/乱动 | 小缺陷 | 运动有动机且克制 |
| 人物连续性 | 身份明显变化 | 小漂移 | 人物服装稳定 |
| 接缝连续性 | 重置/跳变 | 可后期修 | 动量、机位、声音自然延续 |
| 光线与材质 | 虚假/装饰性 | 尚可 | 光服务事件，材质可信 |
| 声音 | 无关或干扰 | 可用底色 | 与画面材质和情绪一致 |

- `ship`：总分 12–14，且人物/接缝均为 2。
- `usable_with_defect`：总分 9–11，记录后期修复项。
- `experimental`：技术有效但不适合正片。
- `reject`：总分低于 9，或存在瞬移、身份切换、无动机切镜。

API `Ready` 不计入上述质量证据。
